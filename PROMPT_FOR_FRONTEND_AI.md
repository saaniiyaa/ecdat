## 5. Contract rules you must honour

1. **Errors** — one envelope everywhere; branch on `error.code`, never on prose:
   ```json
   { "error": { "code": "NOT_FOUND", "message": "…", "details": { "scan_id": "…" } },
     "timestamp": "2026-09-26T18:36:41Z", "request_id": "06855a38e4474bbe" }
   ```
   Codes: `BAD_REQUEST` `UNAUTHORIZED` `FORBIDDEN` `NOT_FOUND` `CONFLICT` `EXPORT_TOO_LARGE`
   `UNSUPPORTED_TARGET` `INVALID_INPUT` `RATE_LIMITED` `SCAN_FAILED` `UPSTREAM_UNAVAILABLE`
2. **Lists** — always `{items,total,limit,offset,has_next}`.
3. **Correlation** — send `X-Request-Id`; the server returns it plus `X-Response-Time-ms`.
4. **Band vocabulary** — exactly `critical | high | medium | low | informational`. Suggested colour
   ramp: critical `#b4232c`, high `#d97706`, medium `#2563eb`, low `#64748b`, informational `#94a3b8`.
5. **Evidence classes** — `PARSED_STRUCTURE` (0.94–0.98, parsed AST/X.509/manifest/config),
   `SYMBOL_INFERRED` (0.70, binary symbol table), `INFERRED` (0.55–0.70, constants/parameters),
   `PATTERN` (0.50, conservative text match). **Show the class as a badge and show
   `capped_by_confidence` when true** — a pattern hit can never be critical, and the UI must not
   imply otherwise.
6. **Timestamps** — ISO-8601 UTC with a trailing `Z`.
7. **Paths** — always POSIX style (`src/main/java/App.java`) on every OS.

## 6. Non-negotiable UX rules (these are the product)

1. **Never say "quantum-safe".** The strongest allowed statement is *"No vulnerable artefacts
   detected **within the scanned scope**"*, always beside the coverage index. The backend exists to
   make that distinction visible; hiding it destroys the whole point.
2. **Every risk number needs its factors.** If you render a score, render the `risk.factors[]` that
   produced it (factor, weight, contribution, explanation) — at least in a drawer.
3. **Classical and quantum are two bars, not one.** They have different owners and different years.
4. **Name the unobserved.** `coverage.unobserved_samples[]` must be visible, e.g.
   `data/blob.dat — partial — binary content in a text-classified file`.
5. **Show where the evidence is**: `file_path:line_start`, the `detector_id`, and
   `snippet_redacted`. The snippet is already redacted by the backend; never re-expose key material.
6. **Respect `key_origin: ephemeral_demo`** in the attestation panel unless a real signing key is set.
